LUNHS v35 — LEAST LEARNED COMPETENCIES / ITEM ANALYSIS

FEATURES
- Teacher selects School Year, Subject/Section, Term, and Exam title
- Manual competency/topic encoding
- Correct count / total learners
- Automatic mastery percentage
- Automatic identification of Least Learned competencies
- Admin-configurable least-learned threshold (default 60%)
- Intervention/remediation and status
- Excel import with preview
- Admin consolidated monitoring by school year
- Teacher can only encode for their assigned subject/section/year
- Existing grades remain separate and unchanged

INSTALL
1. Run V35-LEAST-LEARNED-COMPETENCIES.sql ONCE in Supabase SQL Editor.
2. Upload teacher-competencies.html and admin-competencies.html to the ROOT of LUNHS-PORTAL.
3. Add the teacher link shown in DASHBOARD-LINK-SNIPPET.txt to dashboard.html.
4. Add the admin card shown in ADMIN-LINK-SNIPPET.txt to admin.html.
5. Refresh/reopen the portal.

EXCEL IMPORT
Use the headers in EXCEL-TEMPLATE.csv:
Competency Code | Competency | Correct | Total Learners | Intervention

NOTE
The default threshold is 60%. Admin can change it in the competency monitoring page.
