LUNHS v32.5 — STUDENT MALE/FEMALE ARRANGEMENT

PURPOSE
Existing students can be classified as Male or Female BEFORE teachers encode grades manually.

INSTALL
1. Run V32.5-STUDENT-SEX-GROUPING.sql once in Supabase SQL Editor.
2. Upload/replace these website files in GitHub:
   - dashboard.html
   - admin.html
   - admin-student-sex.html
   - service-worker.js

ADMIN WORKFLOW
Admin > Student Male/Female Arrangement
Choose Grade/Section > Load Students > set each learner to Male/Female > Save.

TEACHER MANUAL GRADEBOOK
When a teacher loads a class, students automatically appear:
MALE — alphabetical by surname, then first name
FEMALE — alphabetical by surname, then first name
SEX NOT SET — students the admin has not classified yet

The official DepEd E-Class Record is NOT changed.
E-Class Record matching remains based on FIRST NAME + SURNAME.
