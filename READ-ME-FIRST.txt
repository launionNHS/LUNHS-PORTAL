LUNHS v32.3 — FIRST NAME + SURNAME MATCHING

The E-Class Record importer now matches learners primarily by:
1. FIRST NAME
2. SURNAME

Middle names and middle initials are ignored.
Common suffixes and punctuation are ignored.
DepEd format "SURNAME, FIRST NAME MIDDLE NAME" is supported.
Portal format "FIRST NAME MIDDLE NAME SURNAME" is supported.

If more than one portal learner has the same first name and surname, the importer marks
the record AMBIGUOUS instead of guessing.
