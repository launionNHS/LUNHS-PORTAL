PASSWORD RESET DESIGN

1. STUDENT / TEACHER
Administrator > Users > Reset Password
The Admin sets a new temporary password.
The user's School ID/LRN/Employee ID stays the same.
No email is required.

2. ADMINISTRATOR — WHILE SIGNED IN
Use the new "My Account > Change My Password" button.
Enter the new password twice.
No email is sent.

3. ADMINISTRATOR — IF COMPLETELY LOCKED OUT
Do NOT create a public password-reset endpoint.
Use the Supabase project owner/dashboard to recover the Auth user securely.
This protects the school portal from account takeover.
